# 噗伊大作战

类似《球球大作战》的网页小游戏。主角「噗伊」越吃越大，达到目标质量即可通关。

## 如何游玩

1. 打开仓库后点击 **index.html** 预览，或启用 GitHub Pages 后访问。
2. 也可以本地双击 `index.html` 直接运行（需能加载 `photo/` 目录下的图片）。

### 操作说明

| 设备 | 操作 |
|------|------|
| **手机** | 屏幕左下角虚拟摇杆控制方向与移动 |
| **电脑** | 鼠标移动决定前进方向，**按住左键**前进；松开后约 0.3 秒内减速停止 |

纯 HTML5 Canvas + 原生 JS，无第三方依赖，电脑与手机均可游玩。
